# 📦 UC6 – Queue + Stack Based Palindrome Checker

## 📌 Overview
This project demonstrates palindrome validation using two data structures:

- Queue (FIFO – First In First Out)
- Stack (LIFO – Last In First Out)

By inserting characters into both structures and comparing their removal order,
we validate whether the string is a palindrome.

---

## 🎯 Goal
Demonstrate FIFO vs LIFO behavior using Queue and Stack.

---

## 🔁 Program Flow
1. Enqueue characters into Queue
2. Push characters into Stack
3. Compare Dequeue (Queue) vs Pop (Stack)
4. Print result

---

## 🧠 Key Concepts Used

### 🔹 Queue
A linear data structure that follows the First In First Out (FIFO) principle.

### 🔹 Enqueue & Dequeue Operations
- Enqueue → Insert into queue
- Dequeue → Remove from front

### 🔹 Stack vs Queue
Stack → LIFO (Last In First Out)
Queue → FIFO (First In First Out)

### 🔹 Logical Comparison
Matching dequeue output with pop output to validate palindrome logic.

---

## ⏱ Complexity Analysis
- Time Complexity: O(n)
- Space Complexity: O(n) (Queue + Stack)
